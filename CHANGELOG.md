# Changelog

## 0.2.0 — release candidate (unreleased)

- Refined the P01–P19 interface for compact, readable field use, including the
  course shell, student profiles, boats, faults, Comandate, crews and evaluations.
- Added reviewed student photo scanning and in-place Italian dictation for notes.
- Added CT volunteers and the revised duty proposal, direct day editing and
  session boat assignment workflows.
- Added complete weekly evaluation grids and student history with exact-session
  notes and distinct missing/neutral marks.
- Kept the local 0.1.0 archive compatible and preserved stable record identities
  through ordinary edits. No account, server sync or multi-editor workflow is
  included.

Release remains pending physical microphone and camera/OCR checks on the target
devices. The release date and Git tag will be added only when those checks pass.
After an evaluation save error, the attempted value remains visible for retry in
the current session; leaving that session before retry can discard the attempt.
