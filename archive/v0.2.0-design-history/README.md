This directory preserves the original annotated request, resolved question logs,
mock-review ledger, activation draft and source text. They explain how the frozen
r10 target was reached but are not authoritative and are excluded from the normal
agent read path.

Current sources are:

- `01_PRODUCT_SPEC.md` for behavior and domain rules;
- `02_MVP_SCOPE.md` for included/deferred scope;
- `03_TECHNICAL_DECISIONS.md` for architecture;
- `04_IMPLEMENTATION_PLAN.md` for execution and evidence;
- `docs/post-mvp/06_DESIGN_RULEBOOK.md` and `07_PAGE_CHANGELOG.md` on demand for
  the active UI milestone.
