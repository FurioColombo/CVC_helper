# Caprera App — Codex Working Set

The working set is intentionally small.

Authoritative documents:
1. `01_PRODUCT_SPEC.md` — user-visible behavior and business rules.
2. `02_MVP_SCOPE.md` — MVP boundaries and completion target.
3. `03_TECHNICAL_DECISIONS.md` — stack, persistence and architecture.
4. `04_IMPLEMENTATION_PLAN.md` — ordered execution plan.

Codex should eventually read all four documents before implementation and then follow the Implementation Plan sequentially.

`AGENTS.md` is intentionally not written yet: the autonomous-execution protocol will be finalized first.

`archive/` contains design history only. It is not part of the implementation working set and should not be read by Codex unless a human explicitly requests historical rationale.
