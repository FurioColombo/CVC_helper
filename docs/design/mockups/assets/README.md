# Loghi barche del mock r10

I file `boat-*.png` sono tavole PNG trasparenti normalizzate a `256 × 72` px. Il contenuto è ritagliato con un margine minimo e centrato sulla stessa tavola, così il mock può usare un solo trattamento CSS senza dare peso diverso ai marchi più verticali.

Ordine e associazione dimostrati nella galleria:

1. `rs-quest-complete.png` — RS Quest, asset già presente nel mock;
2. `boat-rs-500.png` — RS 500;
3. `boat-laser-vago.png` — Laser Vago;
4. `boat-rs-toura.png` — RS Toura;
5. `boat-j80.png` — J/80;
6. `boat-first-25-7.png` — First 25.7;
7. `boat-first-27.png` — First 27.

La pulizia generativa è stata usata come passaggio di preparazione e confronto. I PNG consegnati nel mock conservano le immagini fornite come riferimento, rimuovono il fondo esterno e mantengono il fondo nero interno ai marchi First dove fa parte del logo. Sono asset di proposta per la revisione, non ancora asset ufficiali dell'app.
